# 看板中文字库

agent_tasks_cjk_14.c 由 Noto Sans CJK SC Regular（思源黑体）转换，14 px、2 bpp，包含 ASCII 和 GB2312 常用字符。此字体仅供 Agent 看板与其设置页使用；键盘沿用官方 LVGL 输入组件。

原字体来源：https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf

授权为 SIL Open Font License 1.1，完整授权文本见同目录 OFL.txt。字库已使用独立名称 agent_tasks_cjk_14。

重新生成：python3 generate_font.py /path/to/NotoSansCJKsc-Regular.otf。转换器为 lv_font_conv；生成过程中无需 Wi-Fi 凭据或网关令牌。

罕见汉字、部分扩展文字与 Emoji 不在 GB2312 常用字范围，任务标题应优先使用常用中英文。界面图标另使用 LVGL 已有符号字体。
