# VibeMate 里程碑

## 第一阶段：两条链路分别跑通

第一阶段不进行舵机与 CoreS3-SE 的联调。

### A：舵机链路

```text
FE-URT
→ SCS0009 #1
→ SCS0009 #2
```

验收清单：

- [ ] 两颗舵机分别设置不同 ID。
- [ ] 两颗舵机均可独立控制。
- [ ] 确定并记录波特率。
- [ ] 确定并记录供电方案。
- [ ] 记录完整接线方式。
- [ ] 连续动作测试稳定。

### C：显示与通信链路

```text
PC
→ Wi-Fi
→ CoreS3-SE
→ 屏幕
```

验收清单：

- [ ] 官方 StackChan 固件开发环境能够正常使用。
- [ ] CoreS3-SE 能正常编译和烧录程序。
- [ ] 屏幕能够正常显示。
- [ ] Wi-Fi 能够正常连接。
- [ ] PC 可以向 CoreS3-SE 发送测试状态 `RUNNING`。
- [ ] CoreS3-SE 收到状态后，屏幕显示 `RUNNING`。

## 第二阶段：固件控制舵机

```text
CoreS3-SE
→ UART
→ SCS0009 ×2
```

进入条件：第一阶段 A、C 的验收项全部通过。第二阶段再确定 UART 引脚、供电共地、协议适配及固件集成方案。
