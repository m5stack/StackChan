# VibeMate 状态协议

## 目标

定义 PC 端与 CoreS3-SE 之间的 Coding Agent 状态消息。当前仅建立文档骨架，不锁定传输实现。

## 第一阶段最小消息

PC 发送：

```text
RUNNING
```

CoreS3-SE 接收成功后在屏幕显示：

```text
RUNNING
```

## 待确认项

- [ ] 传输方式：HTTP、WebSocket、TCP 或 UDP。
- [ ] PC 与设备的发现、IP 配置方式。
- [ ] 消息编码、换行和大小限制。
- [ ] 心跳、超时、断线重连与状态过期规则。
- [ ] 状态集合及状态切换规则。
- [ ] 协议版本与向后兼容策略。
- [ ] 是否需要鉴权或局域网访问限制。

| --- | --- | --- | --- |
