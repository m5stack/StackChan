# 首页上滑响应与各 Agent 完成度

用户反馈 AI AGENT 页需反复上滑才能唤出首页按钮。根因之一是 AI 工作任务持有 LVGL 全局锁休眠 100 ms，使触摸采样、绘制与手势处理一同延后。另有公共手势触发区窄、只在释放时判断，以及首页按钮隐藏动画结束标志未在重新显示时清理的问题。

## 最终方案

- AI 工作任务仍以 20 ms 周期处理导航，忙碌时只将头像工作限制为 120 ms 周期；锁内不休眠。
- 公共首页手势从底部 40 px 起触，向上移动至少 40 px 且纵向位移大于横向位移时触发，一次触摸最多触发一次；支持释放时最后触点，排除中部滚动、横滑和短拖动。
- 重新显示首页按钮时清除上一轮隐藏标志，避免动画完成时又隐藏。
- 看板导航按约 33 ms 更新，任务数据按 500 ms 刷新；拷贝快照在 LVGL 锁外完成，标记透明度仅在实际值变化时更新。网络轮询仍为约 1 秒。
- 按用户最终要求，Codex 和 Claude 名称右侧分别以 14 px 小号数字显示完成百分比，不显示底栏、进度条和计数，保留原任务列表高度。
- 百分比按各自当前同步清单的已完成数 / 总数计算，四舍五入；进行中不计完成，空清单显示 `--%`，离线保留最后快照比例。

## 验证

宿主测试覆盖空清单、双 Agent 独立比例、取整、100%，以及底部上滑、横滑、短拖、中部滚动、触点无效和单次触发。ESP-IDF 6.1 构建，USB 仅写应用槽，保留 NVS、OTA 元数据和 assets。首次优化固件刷入后，用户确认“返回顺畅，百分比显示正常”；顶部各 Agent 百分比版本另行记录构建与刷写结果。
