# Local Control Debug Events

Generated by `tools/generate_api_docs.py`. Do not edit by hand.

These notifications are delivered on the authenticated local-control
WebSocket after `debug/subscribe_events` succeeds.

Envelope:

```json
{
  "jsonrpc": "2.0",
  "method": "debug/event",
  "params": {
    "fields": {
      "mode": "auto"
    },
    "ts_ms": 123456789,
    "type": "listen_enter"
  }
}
```

## Event Index

- `state_transition`: Device state changed.
- `wake_word_detected`: Wake word engine detected a phrase and queued wake handling.
- `listen_start_requested`: An explicit local listen request was queued.
- `listen_enter`: The device entered listening state.
- `listen_stop_requested`: A listen stop request was queued.
- `listen_stop_handled`: The listening state handler processed a stop request.
