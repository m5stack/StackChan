## 范围

- 保存并注明 StackChan 官方或社区结构文件的来源与许可证。
- 记录 3D 打印材料、层高、支撑和打印参数。
- 记录 CoreS3-SE、两颗舵机、线束和外壳的装配验证。
- 保存修改后的 STL/CAD 及 VibeMate 外观版本。

## 建议目录

```text
mechanical/
├── official/       # 官方原始结构文件及来源说明
├── cad/            # 可编辑 CAD 源文件
├── stl/            # 可直接打印的导出文件
└── assembly/       # 装配照片、尺寸和问题记录
```

需要 Git 跟踪的空目录应在加入实际文件时再创建。
