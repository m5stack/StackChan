# SCS0009 舵机连续动作稳定性测试报告

## 一、测试环境

| 项目 | 参数 |
|------|------|
| 舵机型号 | SCS0009 |
| 测试数量 | 2 台（ID=1、ID=2） |
| 通信端口 | COM7 |
| 波特率 | 1,000,000 bps |
| 通信协议 | SCS 串行总线协议（半双工） |
| 测试程序 | `hardware/test.py` |
| 供电方式 | 5V 直流稳压电源 |

## 二、测试目的

验证 SCS0009 舵机在"前进→停止→回中→关闭扭矩"完整动作序列中的连续执行稳定性，包括：
- 位置重复精度（前进/回中往返一致性）
- 通信可靠性（丢帧/校验错误率）
- 错误码监控（运行过程是否触发报警）

## 三、测试方法

1. 通过串口依次对 ID=1 和 ID=2 舵机下发指令
2. 单次测试流程：
   - 写入扭矩使能（ADDR=40, VAL=1）
   - 写入目标位置前进 50 步（ADDR=42）
   - 延时 1 秒后下发停止指令（INST=0x07）
   - 回中至初始位置
   - 关闭扭矩使能（ADDR=40, VAL=0）
3. 每步动作后回读当前位置（ADDR=56）和错误码（ADDR=41）
4. 记录实际到达位置、误差值及错误码

## 四、测试结果

|--------|---------|---------|------|--------|

| 前进 | 910 | 909 | -1 | 0x00 |
| 回中 | 860 | 860 | 0 | 0x00 |

### 4.2 ID=2 舵机

|--------|---------|---------|------|--------|
| 初始位置 | — | 259 | — | 0x00 |

### 4.3 汇总

| 指标 | 结果 | 判定 |
|------|------|------|
| 位置重复精度 | 最大误差 ≤ 1 步（≈0.36°） | ✅ PASS |
| 通信成功率 | 100%（无丢帧、无超时） | ✅ PASS |
| 错误码 | 全程 0x00（无过流/过温/过载） | ✅ PASS |

## 五、结论

- 两台 SCS0009 舵机在连续"前进→停止→回中"动作中表现稳定，往返位置重复精度 ≤ 1 步，通信链路无异常。
- 建议在正式集成到 VibeMate 项目后，进行长时老化测试（≥2 小时连续循环），以进一步确认热稳定性。
