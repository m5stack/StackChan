# VibeMate 硬件电控

负责人：唐英杰

## 范围

- SCS0009 舵机 ID、波特率和控制测试。
- FE-URT 与舵机总线连接。
- 供电、电流能力、共地、UART 和接线记录。
- 连续动作与硬件稳定性验证。

## 第一阶段

```text
FE-URT
→ SCS0009 #1
→ SCS0009 #2
```

第一阶段不连接 CoreS3-SE。先使用 FE-URT 完成两颗舵机的独立控制与稳定性验证。

## 实验记录模板

| 项目 | 记录 |
| --- | --- |
| 舵机型号 | SCS0009 |
| 舵机 ID | 1（#1）、2（#2）|
| 波特率 | 1000000 |
| 舵机供电 | 5V 3A 电源适配器 |
| FE-URT 供电 | 5V 3A 电源适配器（同端子侧供电）|
| 接线定义 | 调试板→舵机1(ID=1)→舵机2(ID=2)，三线排线串联，GND共地 |
| 测试程序/工具 | FST Servo Debug |
| 连续动作时长与结果 | 建议速度500，实测曲线平稳；目标值增大→逆时针，减小→顺时针 |
| 已知问题 | 中位512（对应150°）;安全角度≈6°至294°（限位20至1003）;软限位N_Limit=20，P_Limit=1003 |

> 接线或上电前先核对额定电压、极性和共地要求；不要由不确定能否承载舵机电流的接口直接供电。
